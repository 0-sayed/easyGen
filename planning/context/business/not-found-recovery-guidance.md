# Not-Found Recovery Guidance

## Goal

Make the existing not-found message tell users how to recover.

## Scope

- Change `This route does not exist.` to `Check the address or choose where to go next.`
- Update the focused frontend coverage.
- Preserve the existing layout, styling, requested path, and navigation links.

## Acceptance Criteria

- The not-found page displays the new recovery guidance.
- Focused frontend tests and the repository validation command pass.
- Browser QA confirms the page has no overlap or horizontal overflow.
