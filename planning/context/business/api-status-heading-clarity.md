# API Status Heading Clarity

## Goal

Make the application status heading more concise.

## Scope

- Change the status panel heading from `API connection` to `API status`.
- Update the focused component coverage.
- Preserve status loading, success, and failure behavior.

## Acceptance Criteria

- The application status panel displays the new heading.
- Focused frontend tests and the repository validation command pass.
- Browser QA confirms the status panel has no overlap or horizontal overflow.
