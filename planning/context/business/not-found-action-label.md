# Not-Found Action Label

## Goal

Clarify the secondary action on the not-found page.

## Scope

- Change the secondary action label from `Open app` to `Open application`.
- Update the focused component coverage.
- Preserve the destination, layout, styling, and primary sign-in action.

## Acceptance Criteria

- The not-found page displays `Open application` and still links to `/app`.
- Focused frontend tests and the repository validation command pass.
- Browser QA confirms the action row has no overlap or horizontal overflow.
