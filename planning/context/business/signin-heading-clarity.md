# Sign-In Heading Clarity

## Goal

Make the sign-in page heading more direct.

## Scope

- Change the sign-in heading to `Access your account`.
- Update the focused component coverage.
- Preserve authentication behavior, layout, styling, and error states.

## Acceptance Criteria

- The unauthenticated sign-in page displays the new heading.
- Focused frontend tests and the repository validation command pass.
- Browser QA confirms the sign-in card has no overlap or horizontal overflow.
