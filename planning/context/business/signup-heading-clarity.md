# Sign-Up Heading Clarity

## Goal

Make the sign-up page heading more welcoming.

## Scope

- Change the sign-up heading from `Create account` to `Create your account`.
- Update the focused component coverage.
- Preserve authentication behavior, layout, styling, and error states.

## Acceptance Criteria

- The unauthenticated sign-up page displays the new heading.
- Focused frontend tests and the repository validation command pass.
- Browser QA confirms the sign-up card has no overlap or horizontal overflow.
